## [0.1.0] - 2026-05-08

### ✨ Features
- Initial release of CRealizr D&D toolkit
- Encounter Builder with 2014/2024 ruleset support
- Monster Scaler with CR-based stat adjustments
- Artifact Forge for item creation and crafting
- Travel Encounters generator with terrain-based encounters
- Multi-language support (English, Italian, French, German, Russian, Greek)
- Seasonal theme system with FFXIV-inspired color schemes
- Export functionality (PNG/PDF) for all tools
- Responsive design with mobile support

### 🏗️ Architecture
- Next.js 16 with TypeScript
- Tailwind CSS for styling
- Internationalization with next-intl
- Component-based architecture
- Theme context system for seasonal theming

### 🎨 Design
- Fantasy-themed UI with gold accents
- Glassmorphism effects and backdrop blur
- Consistent spacing and typography
- Dark mode optimized color schemes
- Mobile-first responsive design

### 📚 Documentation
- Comprehensive component documentation
- Multi-language support documentation
- Tool-specific guides and examples
